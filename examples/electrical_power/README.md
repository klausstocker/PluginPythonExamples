# Electrical power example

## Learning goal

Learners use descriptive variables and the formula `P = U * I` to calculate
electrical power.

## Task

Write `calculate_power(voltage, current)` and return the electrical power in
watts. Store the multiplication result in a variable named `power_watts`
before returning it.

## Files

- `answer.py` contains a demonstration and the reference implementation.
- `test_answer.py` tests the calculation with different measurements.

This example needs only Python's standard library.

## Run the tests

```bash
python -m unittest discover -s examples/electrical_power -p "test_*.py"
```
